# -cpp-data-structures

## C++ projects by purpose

Every retained project is named for what its code does. The six numbered collections preserve the earlier homework grouping, with descriptive titles in place of homework labels. Each distinct program has its own folder. Empty files, exact duplicates, whitespace-only versions, and alternate implementations are excluded.

The selection keeps the complete BMI calculator, the input-validating digit reversal program, one student-record program, one Armstrong-number search, one Fibonacci program, the documented sphere implementation and its matching header, and the data-cache simulator with Ariel's attribution. This selection is based on code inspection, not proof that one version is the latest or passes all assignment requirements.

Source file contents are unchanged. Generic names such as q2.cpp and Source.cpp are replaced with descriptive names; existing class and header names remain where they describe the code and preserve includes. In the stack project, the actual stack implementation from evaluate.hpp is named Stack.hpp; the other original Stack.hpp was a duplicate of the RPN evaluator and is omitted. This restores the intended file placement without changing its contents.

file-map.csv links every retained file to its original name and SHA-256. selection-record.csv accounts for all 77 originally collected files. Originals and earlier full collections remain untouched. This repository contains the selected collection.

## Existing limitations

- hollow-rectangle-draft and loan-payment-calculator-draft contain syntax errors.
- bubble-sort-starter has an empty sorting function and is a distinct unfinished exercise, not an empty file.
- merge-intervals-test-driver is missing its referenced MergeIntervals.cpp implementation.
- polynomial-demo.cpp includes polynomial.h while the supplied header is Polynomial.h; this is a case-sensitive-system issue.
- data-cache-simulator needs trace.config and trace.dat, which are not part of this source/header collection.
- Library projects may not include a main function. No programs were compiled or run.
- Original Visual Studio project files are not carried into this renamed source collection because they refer to the old paths. They remain available in the earlier full collection.
